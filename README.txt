RICHBOSS333 CLICKABLE WEB PRESENTATIONS

This folder is ready for a static host such as GitHub Pages or Netlify.

How it works:
- The promotional artwork is displayed responsively.
- Invisible percentage-based link overlays sit directly over the artwork's main CTA buttons and selected music-service logos.
- Main CTAs point to RichBoss333's YouTube channel.
- Verified Spotify, Apple Music, YouTube, and Amazon Music logos point to their corresponding artist destinations.
- No Tidal hotspot was added because a verified direct RichBoss333 Tidal profile URL was not available.

Files:
- index.html
- assets/*.png

Open index.html locally in a browser to test the clickable regions before publishing.
